# ADR-0007：P3 自省层与目标层的工程决策

- 状态：已接受（2026-10-17，P3 实施）
- 背景：P3 要把论文 3.2（自省层）与 3.3（目标内生层）落成代码。两层的理论地位是 B/C 级，工程决策全部围绕"如何诚实地模拟并使其可测量"展开。

## 决策一：自省报告作为 system_derived 事件进入总线与指标

自省报告转为 `ObservedEvent(provenance=system_derived, chain_depth=1)` 上事件总线——它本身就是论文 4.3 / OQ4 要测量的"自生内容"，让它进入观测流而非旁路，审计指标（system_derived_ratio）才有意义。

## 决策二：目标 ID 按（模板，标题）确定性生成 + 冲突刷新

**理由**：目标必须跨周期幂等（同一缺口不应每天产生新目标）；同时缺口复现时优先级/溯源要刷新（保鲜）。`INSERT ... ON CONFLICT (goal_id) DO UPDATE` 一次满足两者。
**后果**：模板标题必须跨周期稳定——deadline-prep 用事项主体（不含天数）、theme-cluster 用主题词、contradiction-scan 聚合为单一稳定标题。这条约束反过来约束了模板设计，是 OQ7 测试时要注意的变量。

## 决策三：启发式 Ĝ 近似为显式加权和，不学习

`priority = 0.6 * info_gain + 0.4 * practical_value`，两项分别近似论文 3.3 改造 EFE 的认识价值/实用价值；权重是代码常量，文档显式标注"非严格构造"（论文 3.3 已声明 Ĝ 是框架性提案）。practical_value 来自 charter 域权重（外源锚定的工程化），匹配不到域时返回 0——不假装所有文本都能归域。

## 决策四：目标全部为 R1 只读型，无 R2/R3 目标

P3 阶段模板只合成"整理材料/梳理清单/列出待确认项"三类只读认知目标。对外行为（提醒、发送、修改）留给 P4 门控层——与 ADR-0003 的"内生目标限定只读型"一致。

## 决策五：主题聚类用二元组频次，停用词表显式维护

无分词器依赖的轻量近似：标题/内容的中文二元组频次 + 显式停用词表（我们/可以/完成/相关…）。已知局限：会产生"项目""测试"这类宽主题——这正是 [B-simulated] 标注的内容，也是 P6 主题聚类质量实验的基线。
