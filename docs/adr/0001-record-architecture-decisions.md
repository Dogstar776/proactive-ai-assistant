# ADR-0001：记录架构决策

- 状态：已接受（2026-10-17）
- 背景：本项目以"全程可记录"为核心交付要求之一（理论→DEMO→证据链）。架构决策若不落文字，后期无法区分"当时为什么这么选"与"后来将错就错"。

## 决策

采用轻量 ADR（Architecture Decision Record）制度：每个影响项目方向的决策一篇，编号递增，永不删除（状态可改为"已取代"）。

## 格式

```markdown
# ADR-NNNN：标题
- 状态：提议中 / 已接受 / 已取代（by ADR-XXXX）/ 已废弃
- 背景：问题与约束
- 决策：做了什么选择
- 理由：为什么（含被否决的备选及否决原因）
- 后果：正面 / 负面 / 后续观察
```
