# ADR-0005：常驻成本控制策略

- 状态：已接受（2026-10-17，P0 确认）
- 背景：论文 4.4 论证常驻认知的成本结构 ∫r(t)·c_cycle dt 无天然停机点，商业比率（内生开销:外生价值）约 100:1~1000:1；4.4 同时指出认知周期调度是 C 级问题（自指结构，无最优解）。

## 决策

1. **两层频率架构**：高频轻观测层（分钟级，本地规则解析，**不调用 LLM**）+ 低频深周期层（默认 1–2 次/天，LLM 执行自省与目标维护）；
2. **事件驱动的即时深周期**：显著变化事件可申请一次深周期，受每日预算上限约束（防事件风暴）；
3. **MockLLM 为默认运行模式**：开源复现不需要任何密钥；真实模式经 `.env` 注入 provider；
4. **成本仪表化**：每次周期记录 token 消耗与费用，仪表盘展示——同时作为 OQ5 剂量—效应曲线的采集通道；
5. **每日预算硬上限**：超限自动降级为轻观测 + 告警，不允许静默超支。

## 理由

- 论文 4.4 已证"追求最优调度"是 C 级陷阱；本决策不假装最优，只保证**可负担 + 可测量**；
- 高频层用本地规则而非 LLM，是把论文中"观测成本—覆盖权衡"转成可调参数（规则集规模 vs 覆盖率），可实验；
- MockLLM 默认让 `git clone` 即可运行，是开源项目的基本礼仪。

## 被否决的备选

- **分钟级全 LLM 常驻**：成本结构即论文 5.4.4 演示的商业不可行形态，个人项目直接复现其失败无意义；
- **纯事件驱动（无常驻周期）**：退化为任务驱动 Agent，丧失 P1/P2 的结构特征，实验失去对象；
- **本地小模型全栈**：端侧能力不足且工程量大，provider 抽象已覆盖"可替换"需求。

## 后果

- 正面：月成本可控（个位数到两位数人民币量级）；实验节奏与个人生活兼容；
- 负面：低频深周期意味着"主动性"以天为粒度呈现，短期演示观感弱于商业产品（接受，见 ADR-0003）；
- 后续观察：P6 用实测数据回答 OQ5——当前 1–2 次/天是否落在"非空工作区间"。
