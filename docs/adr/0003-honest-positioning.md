# ADR-0003：诚实定位——受限常驻实例 + 实证仪器

- 状态：已接受（2026-10-17，P0 确认）
- 背景：论文第 5 章已论证：主动式 AGI 的 C 级模块（内生价值可计算判据、可靠元自省、记忆认知健康管理、最优调度、常驻尺度有效监督）在当前理论下不可实现；论文 5.2 结论三给出的唯一负责任路径是"受限常驻系统"。

## 决策

本项目对外与对内统一定位为：

1. **FL-PCL 五层闭环的受限常驻实例**：限定域（个人日程/笔记/信息流）、限定自主性（内生目标只读型，外部行为一律请示）、限定时限（以周/月为测量窗口，不宣称常驻）；
2. **实证仪器而非智能宣称**：核心交付物之一是测量协议与数据（OQ5 剂量效应、OQ7 模板移除、记忆健康指标）；
3. **B 级模块显式标注**：自省层与目标合成层在代码注释、文档、UI 中携带 `[B-simulated]` / `template-based` 标记；
4. **不使用"实现主动式 AGI / 接近 AGI"类表述**（README、简历、宣传物料统一遵守）。

## 理由

- 论文 5.2 给出了可证伪判别准则（目标内生判据不依赖人工模板 + 自省经独立信号源长期校准），本项目主动接受其检验，反而获得市面产品不具备的可信度；
- 2026-10 市面调研（`docs/RESEARCH-2026-landscape.md`）显示：全部商业产品均不触碰目标来源结构，"主动性的计量基准"是空缺生态位；
- 对简历的价值：面试场景中"我画得出自己项目的范式坐标"比"我做了个 AGI 演示"更难被反问击穿。

## 被否决的备选

- **"接近 AGI 的个人助理"式宣称**：不可证伪，懂行面试官按论文 2.4 一问即倒，声誉风险远大于收益；
- **隐藏 B 级模块的模拟本质**：与论文自身立场冲突，且剥夺了 OQ7 实验的意义。

## 后果

- 正面：项目具备学术诚信姿态；P6 实验数据天然可发表；README"这是什么/不是什么"表成为最好的自我介绍；
- 负面：宣传上"不唬人"，需要靠工程质量与实验数据说话；
- 后续观察：若未来获得独立信号源校准手段（如外部验证工具），可按论文判据申请重新分级。
