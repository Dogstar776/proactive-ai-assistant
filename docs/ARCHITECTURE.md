# 架构设计：FL-PCL 五层 → 工程模块

本文是论文第 3 章五层持续认知闭环架构（FL-PCL）的工程设计展开。**设计约束直接来自论文**：论文判定为 C 级的模块，工程上要么不做，要么做了必须显式标注为"模拟"并接受实验测量，不得伪装。

## 1. 分层映射总表

| 论文层 | 论文判据 | 工程模块（P2 起提交于 `assistant/`） | 诚实标注 |
|---|---|---|---|
| L1 环境持续观测层 | P2 | `collectors/`：日历/待办连接器、笔记文件夹连接器、RSS 连接器、内源探针 | A 级，可真实实现 |
| L2 内部认知自省层 | P3 | `introspection/`：缺口检测、一致性审计、自省报告生成 | **B 级，模板+单轮反思的循环调用，标注"模拟自省"** |
| L3 自主目标内生层 | P4 | `goals/`：模板化目标合成、统一优先级队列、charter 锚定 | **B 级，`template-based` 显式标注，接受 OQ7 模板移除测试** |
| L4 任务规划与执行层 | — | `executor/`：规划、工具调用、执行监控、记忆回写 | A 级，五层中唯一整体 A 级 |
| L5 人机可控安全对齐层 | P5 | `gateway/`：风险分级门控、沉默-询问-协助-行动四态、consent ledger、审计日志 | A 级门控 + B 级内生行为风险分级（标注） |

| 横切：仪表盘 | — | `dashboard/`：React+TS，认知环可视化、charter 编辑器、成本面板 | — |

## 2. 认知周期与调度（论文 3.0 / 4.4）

论文指出常驻的成本结构是 ∫r(t)·c_cycle dt，且周期调度问题具有自指结构（C 级，无最优解）。工程上的诚实回应——**不追求最优，追求可测量与可负担**：

- **高频轻观测层**（分钟级）：本地规则解析，不调用 LLM，只做事件抽取与变化检测 → 事件总线；
- **低频深周期层**（默认 1–2 次/天，可配置）：调用 LLM 执行自省报告与目标队列维护；
- **事件驱动的即时周期**：显著变化事件（如连续多个高优先级日程冲突）可申请一次深周期，受每日预算上限约束；
- 每次周期记录 token 消耗与成本，仪表盘可视化——**这就是 OQ5 剂量—效应曲线的数据采集通道**。

## 3. 目标层设计：模板诚实与 charter 锚定（论文 3.3）

论文 3.3 的核心改造：目标优先级判据 Ĝ 的实用价值项必须由人类价值观**外源锚定**（C_human），否则目标生成滑向无约束探索。工程对应：

```
charter.yaml（人类撰写，Git 版本管理）
├── preferences         # 偏好陈述（自然语言 + 示例）
├── value_anchors       # 价值锚点（如：家庭时间 > 工作效率 > 信息获取）
├── risk_policy         # 风险授权策略（哪些类别永远请示、哪些可自主）
├── quiet_hours         # 免打扰时段（沉默的硬约束）
└── domains             # 关注的域（求职/健康/学习/关系…）与各域权重
```

目标合成的每次输出都携带 `provenance: template-based` 标记与所用模板 ID；目标谱系（目标→子目标→执行→回写）全链记录，供 OQ7 模板移除测试使用（移除模板后测量目标队列的退化曲线）。

## 4. 对齐层设计：四态门控与授权硬约束（论文 3.5 / P5）

继承论文引用的 Tang et al. 主动服务 Agent 框架——沉默（silence）/询问（ask）/协助（assist）/行动（act）四态，并按论文扩展为**内生行为**的分级：

| 风险级 | 行为类型 | 门控策略 |
|---|---|---|
| R0 纯内部认知 | 自省、记忆整理、目标排序、报告生成 | 自动执行，留痕 |
| R1 只读外部 | 信息检索、日历读取、笔记解析 | 自动执行，留痕，纳入 consent ledger |
| R2 低风险外部 | 草拟内容、整理待办建议、生成简报 | 生成后进入"待确认"队列，不直接触达用户 |
| R3 高风险外部 | 任何状态不可逆修改、对外通信、支付、删除 | 挂起并请示；超时策略=默认不行动（论文：沉默的选项价值） |

**抗授权疲劳**（论文 4.5 指出监督注意力稀释是结构性的）：批量审计模式——R2/R3 项在人类在场时一次性呈现，支持一键批量批准/拒绝；仪表盘展示"本周请示次数 vs 批准率"，作为授权疲劳的自检指标。

## 5. 数据与隐私架构（ADR-0004）

- **本地优先**：SQLite + ChromaDB 落在本机 `data/`（gitignored）；无云端同步，无遥测；
- **consent ledger**：每次采集记录——来源、范围、时间、授权 ID、用户可见；
- **provenance 溯源**：每条记忆标记来源（用户注入/系统回写/外部检索）与生成链深度，服务 OQ4 记忆健康指标；
- **密钥**：只进 `.env`（gitignored），`.env.example` 仅占位。

## 6. 接口约定（REST + SSE）

- REST：`/api/v1/events`（观测事件流）、`/api/v1/introspection/reports`、`/api/v1/goals`（队列 CRUD + 授权动作）、`/api/v1/charter`（读写锚定文件）、`/api/v1/audit`（consent ledger 与决策日志）、`/api/v1/costs`（周期成本）；
- SSE：`/api/v1/stream`——观测事件、自省报告、门控决策实时推送仪表盘；
- 错误：类型化错误体 `{code, message, request_id}`，4xx 不重试、5xx 前端最多重试 3 次；
- 单用户本地部署，绑定 127.0.0.1，v0 无鉴权系统（ADR-0002）。

## 7. 与论文表 2（A/B/C 分级）的对账

本架构的每个模块在代码注释与文档中携带分级标记（`# [A]` / `# [B-simulated]` / `# [C-instrumented]`）。C 级模块（无任务选择性注意、内生价值可计算判据、记忆认知健康管理、最优调度）**不以功能形式宣称，只以测量仪表形式存在**——这是本项目与一切"AGI 演示"的结构性分界。
