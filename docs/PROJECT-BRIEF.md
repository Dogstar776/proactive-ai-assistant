## 一句话

一个由 211 本科应届转型者与 AI 协作完成的开源项目：**把一篇主动式 AGI 理论论文，
落成了“理论 → 工程 → 实证”三件套**——可运行的受限常驻系统、安卓 APP、
以及把论文判别准则变成可复现实验的测量设施。

## 三十秒版（电梯陈述）

> 市面上所有 AI 助理的“主动”都是对时间/地点/习惯的预判式服务，目标永远来自用户或厂商。
> 我们先写了一篇理论论文，论证什么叫真正的“主动”（无指令下持续观测、自省、内生目标），
> 并用可证伪判据指出：当前全部商业产品都只是“主动行为的模拟”。
> 然后把论文落成了开源实现：本地授权感知 → 规则自省 → 模板化目标合成 →
> 四态门控（沉默/询问/协助/行动）→ 手机 APP 通知闭环。
> 最硬的一个结果：我们做了“模板移除测试”——移除目标模板后，
> 系统缺口检测不变但目标生成归零，用实验证明了自身“模拟主动性”的边界。
> 不装 AGI，只做可测量、可复现的诚实系统。

## 关键技术决策（每个都有 ADR 记录，共 9 篇）

1. **诚实定位**：不宣称实现主动式 AGI，B 级模块显式标注“模拟主动性”，用论文判别准则自我检验；
2. **授权持续感知**：consent ledger 授权账本 + 全量审计日志 + 本地优先，数据不出本机；
3. **可审计的沉默**：系统决定不打扰时也留痕（status=suppressed + 原因），人类可区分“认为不该说”与“没说”；
4. **常驻成本控制**：高频轻观测用本地规则（零成本）+ 低频深周期 + MockLLM 无密钥复现；
5. **确定性幂等**：事件/目标 ID 按内容哈希生成，重复采集不膨胀。

## 可写进简历的成果（均有代码/测试/文档佐证）

- 独立完成**主动式 AGI 理论论文**（三范式七维度判据体系、五层持续认知闭环架构、五大理论困境论证、七条开放研究问题），并以开源工程完整落地；
- 工程实现**受限常驻 AI 助理系统**：Python/FastAPI 后端（54 个测试）+ React 仪表盘 + **Kotlin/Compose 安卓 APP**（API Key 鉴权、后台周期同步、通知栏动作闭环），端到端可运行；
- 设计并实现**四态门控**（沉默/询问/协助/行动）与“可审计的沉默”机制，对应人机对齐中的授权疲劳与监督稀释问题；
- 完成 **2026 主动式 AI 助理市面调研**（STEPX Neo、Apple Siri AI、ChatGPT Dreaming V3 等 10+ 产品），按论文 P1–P5 判据完成竞品体检，定位“主动性计量基准”空缺生态位；
- 搭建**实证实验设施**：OQ7 模板移除测试（实测：目标生成能力下降 100% 而缺口检测不变）、OQ5 剂量效应测量、OQ4 记忆健康指标，支撑第二篇实证论文。

## 诚实边界（面试被问到时这么答）

- 本项目**不是 AGI**，是论文处方的“受限常驻实例 + 实证仪器”；
- 目标合成是模板驱动的（论文 5.2 意义上的“主动行为的模拟”），OQ7 实验就是证明这个边界的；
- 自省层是规则近似，标注 `[B-simulated]`，不是可靠元认知；
- 安卓 APP 未经真机验证（CI 构建通过为当前验证边界）；
- 单被试 14 天运行是探索性数据，不是统计功效充分的实验。
