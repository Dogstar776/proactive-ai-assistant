# 市面调研：2026 主动式 AI 助理全景与本项目定位

> 调研日期：2026-10-17 ｜ 调研人：吴子健（项目维护者）｜ 用途：校准项目定位、补充论文论据、明确差异化
>
> 本文是项目 P1 的阶段产物。所有系统描述来自公开报道（文末列出来源）；用论文《主动式AGI的理论框架与落地约束》第 2 章 P1–P5 判据逐一体检。

## 0. 结论速览

1. **市场确实进入了"主动式 AI 助理"产品化元年的氛围**，但用论文判据检验：2026 年全部代表性产品——从 3999 元的智能体手机 STEPX Neo 到 ChatGPT Dreaming V3——**没有任何一个满足主动式 AGI 的 P4（目标内生）条件**。它们的"主动"是**对外部信号（时间/地点/习惯/屏幕内容）的预判式服务**，论文 2.4 节称之为"主动行为的模拟"，且 2026 年的产品把这种模拟做到了消费级完成度。
2. 市场验证了论文的两个核心判断：**竞争全部集中在执行端**（场景数量、跨 App 调用、生态合作），评价端（提醒是否值得、目标是否该生成）无厂商作为卖点（论文 5.2 结论二）；**责任不可保的自主不被允许**——ChatGPT Dreaming 在欧盟被 GDPR 直接封锁（论文 5.4.4 的市场投影）。
3. **本项目的生态位因此清晰：不做第 6 节所列"赢不了"的竞争，做市面空缺的三件事**——目标来源结构的可测量化（OQ7）、主动性的计量基准、数据主权与全链路可审计的个人助理。

## 1. 调研范围与方法

四类玩家：①智能体手机（软硬模一体新品）②系统级 AI 助手（既有厂商升级）③云端个人智能体（记忆架构重写）④第三方记忆层（跨 AI 的记忆主权产品）。每类取 2026 年最有代表性者，按论文 P1–P5 判据体检。

## 2. 市场全景

### 2.1 智能体手机：软硬模一体

**STEPX Neo（阶跃星辰，2026-10-13 发布，全栈定价 3999 元）**——本轮调研中"主动式"完成度最高的硬件产品，值得逐层拆解：

| 维度 | 事实 |
|---|---|
| 架构 | "软硬模"三位一体：硬件感知与表达 + 模型理解与决策 + 软件调度执行，为个人智能体"阶跃 Amoo"量身打造 |
| 系统 | 从零打造的智能体原生操作系统 StepAOS 1.0，**长期记忆、任务调度、安全机制融入 OS 底层** |
| 主动性设计 | **双入口**：用户主动唤醒 + 智能体主动响应；背部 MiniLED 点阵屏作为"智能体专属表达窗口"，实时呈现智能体状态 |
| 记忆 | **双域记忆**：用户域（沉淀用户偏好）+ 智能体域（沉淀智能体经验） |
| 安全 | "可信、可见、可控、可逆"：任务可追溯、权限由用户掌握 |
| 模型 | 端云协同：端侧快反应（闹钟/系统设置，部分离线），云侧深思考（检索/多应用协同的任务拆解） |
| 感知硬件 | 六麦克风阵列 + 低功耗音频芯片 + Whisper 1.0 拾音算法；智能体 24 小时常运行耗电约 1.2% |
| 生态 | 支付宝（系统级 AI 支付，首个接入 VibePay 的终端厂商）、腾讯 WorkBuddy、携程、滴滴、美团、剪映、高德等近百家企业；开放 MCP、A2A 协议 |
| 商业模式 | 硬件 + StepAOS + StepStudio + Step 模型服务打包；购机送 12 个月每月百亿 Token 额度 |

**努比亚豆包手机二代（2026-09-16 发布）**：字节豆包与努比亚合作路线，全系统级自动化（自动打卡、填表、控灯、发布社交内容），预约量 36 万台。报道明确指出市场存在两条技术路线：**合作适配（豆包）vs 全栈自研（STEPX），互补探索**。

### 2.2 系统级 AI 助手：既有厂商的"主动智能"升级

- **华为 Mate 80 Pro / 小艺**：小艺记忆 + 跨设备协同，记住会议偏好、航班常选座位，出差时主动提醒天气与路况；AITMark 2026 评测综合第一，多轮对话准确率超 90%。
- **OPPO 小布 Next（ColorOS 16，2026-07-27 启动）**：行业首个**端侧 Multi-Agent 协同系统 + 端侧全域记忆系统**；"全时意图感知引擎"结合时间/地点/天气/日程/设备状态主动判断何时提醒；打通 100+ 系统能力；兼容第三方 Agent/Skill/MCP（瑞幸、印象笔记、飞猪、美团）。关键设计：**邮件发送、支付等关键操作"只做准备、不替用户做决定"**；复杂任务经 PCC 安全链路调云端。OPPO 首席产品官刘作虎："主动智能将是 AI 手机真正的拐点。"
- **三星 Galaxy S26 Ultra / Bixby**：升级为对话式设备智能体，"即时简报"从被动响应转向主动服务（晨跑时自动播放上周末配速对比并推荐歌曲）；海报中的日程信息一键入日历。
- **荣耀 Magic8 Pro / YOYO 智能体**：L3 卓越级，覆盖衣食住行购 3000+ 场景。
- **Apple Siri AI（WWDC 2026，iOS 27）**：独立 App + 系统级权限 + 屏幕感知 + 跨 App 操作（App Intents 框架）；复杂推理大脑为**定制版 Google Gemini（约 1.2 万亿参数，年费约 10 亿美元）**；个人化记忆 + 主动建议（常听播客更新时提前 5 分钟通知）；隐私仪表盘可清除记忆缓存；**中国大陆暂不可用**。业界评价：能力与三星 Galaxy AI、豆包、小爱相当，**"追平而非领先"**。

### 2.3 云端个人智能体：记忆架构重写潮（2026 年 3–6 月集中爆发）

- **ChatGPT Dreaming V3（2026-06-04 推送）**：层级化自合成记忆架构——①后台合成引擎跨会话自动抽取结构化事实（无需用户说"记住这个"）；②**条目自更新**（"7 月去新加坡"在行程后自动改写为"2026 年 7 月去了新加坡"）；③相关记忆切片在推理前注入系统提示。事实召回 41.5%→82.8%，计算成本降至约 1/5。**欧盟/英国因 GDPR 封锁**。业内警示："审计负担从'我说过什么'变成'模型推断并悄悄改写了什么'。"
- **Claude Chat Memory（2026-03，全计划可用）**：摘要式轻量路线，跨会话携带上下文。
- **Gemini Personal Intelligence**：连接 Gmail/Photos/Search/YouTube，Daily Brief 从日历与收件箱提取当日重点；默认关闭，声明不用于训练。
- **Grok memory + Skills（2026-05-18）**：跨会话记忆 + 持久化"技能"（格式规则、工作流步骤）。
- **M365 Copilot Memory（2026 年上半年 GA）**：工作场景集成度最高，管理员细粒度管控。
- 行业共识：五家全部是**记忆孤岛**——"没有单一助手拥有最好的记忆，但每一家都把记忆锁在自己产品里"；切换数字大脑的隐性成本估计 2000–4700 美元/重度用户。

### 2.4 第三方记忆层：记忆主权赛道

- **MemoryLake**：用户自持记忆（AES-256、Git 式版本控制），经 MCP 暴露给任何 AI 工具；自称 LoCoMo 基准第一（94.03%）。
- **Hatch**：纯文本记忆文件，用户可逐行查看编辑，"用户的记忆 literally 是一个自己拥有的文件"。
- **Evermind / EverOS**：定位"Agent 的记忆 OS"，多模态可检索、用户可检查编辑，LoCoMo 93.05% / LongMemEval 83.00%。

|---|---|---|---|---|---|
| **P1 常驻运行**（认知不依赖指令持续存在） | △ 工程常驻（低功耗芯片 24h 运行）≠ 认知常驻 | △ 同左 | △ 同左 | △ 同左 | ✗ 会话触发 |
| **P2 持续观测** | ✓ 六麦克风+屏幕+传感器+端云状态 | ✓ | ✓ 全时意图感知引擎 | ✓ 屏幕感知 | ✓ 跨会话合成 |

## 4. 对论文理论的影响：三条验证、两条补充

**三条验证（论文预测被市场印证）：**

1. **5.2 结论二的验证**：所有厂商的竞争叙事都落在执行端——场景数（3000+）、跨 App 编排、生态合作数（近百家）、入网预售量。评价端（"这次提醒是否值得打扰""这个内生目标是否该生成"）无任何厂商作为产品指标。Apple 被评"追平而非领先"，正是执行端竞争饱和的信号。
2. **5.4.4 推演的验证**：论文断言"责任不可保的风险无法定价，无法定价的风险不允许自主"——ChatGPT Dreaming V3 在欧盟被 GDPR 直接封锁，是该断言在 2026 年的字面执行。
3. **2.4 节判据的验证**：STEPX 双域记忆、小布全时意图感知、Dreaming 自更新记忆，均为"更丰富的外生设定在外观上逼近内生主动性"——论文预言的"模拟主动性完备形态"已实体化。

**两条补充（论文 v1.1 可吸收的新论据）：**

1. **4.3 记忆腐化获得消费级实证先例**：Dreaming V3 的"条目自更新"把论文 4.3 的累积失真与自我指涉腐化从月级理论推演变成大众产品问题——"审计负担从我说过什么变成模型推断并悄悄改写了什么"正是 4.3 的通俗版。论文可引用其为"推理时记忆层 model collapse 的消费级先例"（论文 4.3 节原判断"现有模型崩溃文献不直接覆盖"，现可补产品案例）。
2. **5.4.3 数据主权从推演变为商业赛道**：论文关于"个人/边缘级算力独特优势在数据主权"的推演，被 MemoryLake/Hatch 等第三方记忆层产品证实为真实市场需求（记忆孤岛 + 切换成本 + GDPR 缺位）。论文 5.4.3 可增加消费市场佐证；本项目 charter + consent ledger + 本地优先设计正落在这条赛道上。

**对论文立场的影响：不需要修改核心论断，建议在 v1.1 增加一节"市场观察"**（2.5 或 5.3 内），把本文表格作为"模拟主动性"的 2026 年例证库。论文的理论价值不因产品浪潮贬值——反而因浪潮而发生：**判据的需求随宣称的增多而增大**。

## 5. 我们的区别与优势（五条，均为结构性而非功能性的）

1. **唯一以"目标来源结构"为设计对象并使其可测量**：市面产品全部外生目标（指令/信号/模板）；本项目的目标队列带 `template-based` 显式标注 + 目标谱系追踪 + **OQ7 模板移除测试**——把论文 5.2 的可证伪判别准则变成可运行实验。市面没有"主动性的计量基准"，这是空缺。
2. **评价端仪器 vs 执行端内卷**：厂商卷"能做多少事"，我们卷"这次主动干预值多少钱"——提醒精度、沉默率、授权疲劳曲线、记忆健康指标（溯源率/自生内容占比/生成链深度）。论文结论二即本项目的方法论。
3. **数据主权 + 全链路可审计**：consent ledger（授权账本）+ 全量审计日志 + Git 版本化 charter（人类偏好锚定 C_human 的工程化）+ 本地优先数据不出本机。对照 Dreaming 的"悄悄改写"与五家记忆孤岛，这正是 MemoryLake/Hatch 验证过的需求方向，且我们开源可复现。
4. **学术资产化**：论文判据 → 工程规格 → 实验协议，三段同源。作品集里"画得出自己项目在范式地图上坐标"的开发者是极少数——这是本项目对简历的核心增量。
5. **成本结构诚实**：不为"无人值守常驻"的幻觉付费（论文 4.4 已证其商业不可行）——低频深周期 + 高频轻观测（本地规则不调 LLM）+ MockLLM 无密钥复现。

## 6. 诚实的自我评估：我们赢不了什么

- **生态与场景广度**：近百家企业合作、3000+ 场景、系统级支付——不竞争，也不该竞争。
- **硬件感知与端侧算力**：六麦克风阵列、低功耗音频芯片、端云协同调度——个人项目不具备，明确借用（provider 抽象）。
- **模型能力**：不自研模型，做 provider 抽象（OpenAI 兼容 / DeepSeek / Ollama），把模型当可替换部件。
- **结论**：本项目生态位 = **研究仪器 + 个人主权助手**，不在"消费级主动助理"赛道。对简历的价值不在"我做了个打败厂商的助理"，而在"我能在一片喧嚣里画出范式坐标，并把它做成可测量、可复现的开源实证"。
