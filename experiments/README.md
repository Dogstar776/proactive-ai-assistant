# P6 实验设施 · 14 天个人运行协议

> 论文《主动式AGI的理论框架与落地约束》第 6 章 OQ4/OQ5/OQ7 的实证入口。
> **核心事实：数据收集是全自动的**——后端 SQLite 已在记录每一次事件、自省报告、
> 目标入队、门控判决（含沉默）与你的每一次批准/拒绝。本目录的脚本把这些记录
> 聚合成可发表指标。

## 三个实验

| 脚本 | 对应论文 | 测量什么 | 是否需要你操作 |
|---|---|---|---|
| `oq5_dose_response.py` | OQ5 / 4.4 / 4.5 | 采纳率、打扰率、沉默原因分布、授权疲劳趋势 | 只需要对手机通知**诚实点**批准/拒绝（不点也算数据：计入未回应） |
| `oq7_template_removal.py` | OQ7 / 5.2 | 模板移除测试：移除目标模板后系统"想做什么"的能力下降多少 | **零操作**——受控实验，用 fixtures 在临时库跑，不碰真实数据 |
| `memory_health.py` | OQ4 / 4.3 | provenance 分布、生成链深度、自生内容占比趋势、重复率 | **零操作**——纯读生产库 |

## 你需要做的事情（就这些）

**第 0 步 · 接真实数据（一次性，约 10 分钟）**

在 `assistant/.env` 里把采集源指向你的真实数据：

```
COLLECTOR_ICS_PATHS=你的日历.ics        # 飞书/Outlook/Google 日历都能导出 .ics
COLLECTOR_NOTES_PATHS=你的笔记文件夹     # Markdown 目录（ Obsidian/Logseq 库均可）
COLLECTOR_RSS_URLS=常看的源1,源2        # 没有就留空
```

重启后端。之后每次轻观测周期采的就是真实数据。

**第 1 步 · 正常用（14 天）**

- 手机提醒来了 → 按真实判断点批准/拒绝。**这就是实验数据**（OQ5 的 ground truth）。
- 觉得被打扰到的那些，也如实拒绝——拒绝率本身就是最有价值的指标。
- 不需要记日记、不需要截图、不需要任何额外动作。

**第 2 步 · 周期性出报告（我来做或你跑）**

```bash
cd experiments
python oq5_dose_response.py      # 随时可跑，数据越多越有意义
python memory_health.py          # 记忆健康趋势
python oq7_template_removal.py   # 受控实验，随时可跑（约 1 分钟）
```

报告写入 `experiments/reports/`（本地证据，gitignored——含个人数据，不公开）。

**第 3 步 · 14 天后**

三份报告 + 原始记录 = 论文二《受限常驻系统的实证测量》的数据基础；
脱敏后的报告与结论进 GitHub 仓库，成为作品集的实证部分。

## 频率对照（OQ5 的"剂量"轴）

论文 4.4 指出剂量—效应曲线完全未被研究。14 天个人运行的采样设计：

| 阶段 | 天数 | 深周期/天 | 测什么 |
|---|---|---|---|
| 基线 | 1–3 | 1 | 低频率下的提醒质量基线 |
| 中剂量 | 4–7 | 2（默认） | 默认配置的采纳率 |
| 高剂量 | 8–11 | 4 | 频率上升后采纳率/打扰率的变化 |
| 疲劳观察 | 12–14 | 2 | 回到中剂量，观察批准率是否恢复（疲劳可逆性） |

频率切换改 `assistant/.env` 的 `DEEP_CYCLES_PER_DAY` + 重启，到点我会提醒你。
如果你嫌麻烦，也可以全程默认 2 次/天——数据仍然有效，只是少了剂量对照轴。

## 边界声明（诚实）

- 单被试、无对照组、14 天——这是**个人运行的探索性数据**，不是统计功效充分的实验；
  论文里会如实这样写（样本性质决定结论强度）；
- OQ7 是受控实验（同 fixtures、同 charter、唯一变量=模板），可以重复复现，
  这三个里它的结论最硬；
- OQ5 的"采纳率"混有提醒质量与个人心情因素——解读时会标注这个混淆。
